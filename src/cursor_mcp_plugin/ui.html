Step1: Install Cursor
Download and install Cursor from here
Step2: Enable MCP in Cursor
Open Cursor → Settings ⚙️ → Tools & MCP → Add MCP
Step3: Add the configuration
Copy the configuration below and paste it into your MCP settings file. Save with Ctrl+S (Windows) or Command+S (Mac).
{ "mcpServers": { "DesignWithAI": { "command": "npx", "args": [ "-y", "design-with-ai@latest", "--server=my-figma-mcp.onrender.com" ] } } }
Configuration file locations:
For Cursor: Add to ~/.cursor/mcp.json
For Claude: Add to claude_desktop_config.json

About this plugin

This plugin connects Figma to Cursor AI or Claude Desktop using the Model Context Protocol (MCP).

 

Features:

• Read and modify Figma designs

• Create components and frames

• Update styles and colors

• Export designs as images

• Bulk text replacement

• Component instance overrides

• Prototype flow visualization
